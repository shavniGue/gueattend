🟢 Safe Skips Formula (Attendance ≥ 75%)

If your attendance is currently 75% or higher, how many consecutive upcoming classes can you safely miss before dropping below the 75% threshold?

A / (T + k) ≥ 0.75
4A ≥ 3(T + k)
3k ≤ 4A - 3T
k = max(0, ⌊(4A - 3T) / 3⌋)

⌊ ⌋ is floor division (rounding down) so you never accidentally bunk one class too many and drop to 74.9%!

🔴 Catch-Up Formula (Attendance < 75%)

If your attendance is below 75%, how many consecutive classes must you attend without missing any to restore eligibility?

(A + k) / (T + k) ≥ 0.75
4(A + k) ≥ 3(T + k)
4k - 3k ≥ 3T - 4A
k = max(1, ⌈3T - 4A⌉)

⌈ ⌉ is ceiling division (rounding up) so you reach guaranteed safe standing above 75%.

🛡️ The Edge Case Guard (Debarment Protection)

In standard naive rounding, if a student has 74.8% attendance (for example, 74 classes attended out of 99), a basic calculation could round 74.8% to 75% or output 0 classes needed. However, Graphic Era University strictly debars students below 75.00%!

gueattend enforces Math.max(1, needed) whenever percentage < 75.0, ensuring the system always instructs the student to attend at least 1 more class so their official academic status is 100% secure.
